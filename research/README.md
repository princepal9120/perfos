# PerfOS Research Dossier

This folder holds the competitive and technical research that drives PerfOS
product decisions. Everything here is source-grounded (pulled, not invented).

## Contents
- `competitors.md` — feature matrix of Triple Whale, Northbeam, Measured, Sellforte, Lifesight.
- `open_source_ads_mcp.md` — GitHub star audit of the open-source ad-control-plane category (2026).
- `perfos_positioning.md` — how PerfOS differentiates and what to build.
- `landing_page_research.md` — SaaS landing page structure + conversion benchmarks.

## How to use
When adding a feature, check `competitors.md` to see if a market leader already
proves the pattern. PerfOS ships the feature too, but always routed through the
policy gate + audit log (the wedge competitors lack).
